# PYRAXIS — static site

Single-file static website (`index.html` + `public/` assets). No build step, no dependencies to install.

## Run

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Files

- `index.html` — the entire site (markup, styles, scripts; three.js + fonts via CDN)
- `privacy.html`, `terms.html` — legal pages
- `public/` — wordmark, favicon, icons, founder frames
- `sitemap.xml`, `robots.txt` — SEO

## Leads

## Deploy

Upload the folder to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
